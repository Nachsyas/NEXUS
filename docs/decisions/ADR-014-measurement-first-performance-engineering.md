# ADR-014: Measurement-First Performance Engineering

**Status:** ACCEPTED  
**Date:** 2026-10-03  

## Context
Optimasi prematur tanpa pengukuran sering kali menambah kompleksitas kode tanpa memberikan manfaat performa nyata.

## Decision
Seluruh keputusan optimasi wajib didahului oleh pengukuran baseline yang dapat direproduksi dan diverifikasi dengan data pengujian.
