# ADR-006: Native Swift and SwiftUI for iOS Client

**Status:** ACCEPTED  
**Date:** 2026-10-03  

## Context
Klien seluler NEXUS memerlukan akses perangkat keras mendalam (AVFoundation audio tap-to-talk, Action Button via App Intents, Keychain, Push Notifications, dan rendering visual yang mulus).

## Decision
Membangun klien iOS secara murni menggunakan **Swift dan SwiftUI**.
