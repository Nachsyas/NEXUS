# SOP 10 — Documentation Governance

**Status:** CANONICAL SOP  
**Version:** 1.1  

## Aturan Dokumentasi:
- Dokumen kanonikal berada di bawah direktori `docs/`.
- Dilarang menandai fitur sebagai selesai (`IMPLEMENTED`) jika kode belum diverifikasi dengan test.
- Status dokumen yang valid: `PLANNED`, `IN_PROGRESS`, `IMPLEMENTED`, `VERIFIED`, `PARTIAL`, `FAILED`, `DEPRECATED`, `SUPERSEDED`.
