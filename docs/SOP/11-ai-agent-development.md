# SOP 11 — AI Agent Development Protocol

**Status:** CANONICAL SOP  
**Version:** 1.1  

## Panduan untuk AI Coding Agent:
- Selalu prioritaskan arahan arsitektur NEXUS di atas kecenderungan default model.
- Jika menemukan ambiguitas arsitektur, buat ADR bertatus `PROPOSED` dan minta persetujuan pengguna.
- Dilarang keras melakukan refactoring massal pada file yang tidak berkaitan dengan tugas saat ini.
