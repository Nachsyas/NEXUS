# SOP 09 — Debugging & Root Cause Analysis

**Status:** CANONICAL SOP  
**Version:** 1.1  

## Prinsip Debugging:
- Cari akar masalah pada layer yang tepat; jangan menambal gejala di layer UI jika masalah ada di database.
- Tuliskan regression test yang membuktikan bug sebelum memperbaiki kode.
- Pastikan perbaikan lulus seluruh rangkaian test yang sudah ada.
