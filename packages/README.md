# NEXUS Shared Packages

Cross-cutting contracts, protocols, schemas, and constants shared across iOS client, Mac Agent, and Backend services.

## Directory Structure
- `protocols/`: Wire format specifications, WebSocket framing contracts, device trust signatures (ADR-008).
- `schemas/`: Machine-readable data schemas, JSON schema definitions, model event envelopes.
- `constants/`: Canonical system constants, error codes, capability identifiers (ADR-009).
